# Dokumentation: Repo ist selbstständig

Dieses Produkt-Repo (GitHub-Fork) muss **allein** lesbar und nutzbar sein — ohne Nachbarordner oder andere Remotes.

## Verbindlich

1. **Keine Links** aus diesem Repo zu gemeinsamen Workspace-Docs oder anderen Produkt-Repos (`../…`, absolute Workspace-Pfade in Markdown-Links).
2. Was Agenten für **dieses** Projekt brauchen, steht **vollständig** in `docs/` und `AGENTS.md` (besonders `HANDLUNGSANWEISUNG-MORPHOS-AGENT.md`, `HANDLUNGSANWEISUNG-GIT.md`).
3. Übergreifende Learnings werden bei Bedarf **inhaltlich** hier übernommen — nicht nur „siehe Nachbar“.
4. Andere Produkt-Repos unter demselben Workspace **nicht** patchen, solange der Auftrag dieses Repo betrifft.

## Merksatz

**GitHub AmigaGPT (Fork)** = Produkt-Buch, allein lesbar. Keine Rückverweise auf Workspace-Index-Repos.
